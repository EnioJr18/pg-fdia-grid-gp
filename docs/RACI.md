# Matriz RACI

Legenda:
- **R — Responsible:** executa a atividade.
- **A — Accountable:** responde pela entrega/aprovação.
- **C — Consulted:** é consultado.
- **I — Informed:** deve ser informado.

> Substitua as colunas `Integrante 1`, `Integrante 2` etc. pelos nomes ou usuários GitHub do grupo.

## Regra de uso
Cada atividade deve ter pelo menos um **R** e, preferencialmente, um único **A**. As atribuições devem ser coerentes com os **Assignees** das issues no GitHub.
